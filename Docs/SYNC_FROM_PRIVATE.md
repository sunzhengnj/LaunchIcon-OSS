# 私有开发与公开仓同步

LaunchIcon 的日常开发在维护者的**私有仓库**中进行（实验、诊断、未发布里程碑、内部交接文档等）。

本仓库 **LaunchIcon-OSS** 是面向社区的公开源码与发行入口：

- 维护者在认为某个里程碑足够稳定时，会把**经过清理的源码与文档**同步到这里。
- 不是每一个私有 WIP 提交都会出现在本仓。
- 社区贡献（Issue / Pull Request）应针对**本公开仓**提交；维护者会在后续里程碑中吸收合入。
- 私有仓中的内部文件（交接日志、每日审阅、任务板、决策流水账等）**不会**公开。

若你 fork 本仓做实验，请遵守 [Apache-2.0](../LICENSE)，并保留 `NOTICE` 与版权声明。商标与品牌资源的使用见 [README](../README.md) 中的说明。
