# LaunchIcon brand artwork

The icon follows PRD §3.3: LaunchIcon's four rounded color tiles. It does not use LaunchOS, Apple, Finder, or Launchpad artwork.

- `LaunchIcon-AppIcon-Master.png` matches the restored 1024px AppIcon source.
- `LaunchIcon-Brand-Light-Master.png` matches the restored 1024px light README brand source.
- The AppIcon and light/dark brand variants in `Resources/Assets.xcassets/` are the canonical assets, restored from the version before `202ac9b`.

macOS applies the final app-icon mask.
